# appsscript.json の直し方（v1.6・1行足すだけ）

会食カードがカレンダーの「枠・予約」を読むために、**読み取り専用のカレンダー権限**を1つ足します。
予定を作ったり書き換えたりはしません（`calendar.readonly` は読むだけの権限です）。

## 手順（スマホでも Mac でもブラウザで）

1. Apps Script のプロジェクトを開く
2. 左の歯車 **⚙️ プロジェクトの設定** → 「**appsscript.json マニフェスト ファイルをエディタで表示する**」に**チェックを入れる**
3. 左の **< > エディタ** に戻ると、ファイル一覧に `appsscript.json` が出てくるので開く
4. `oauthScopes` の配列の**いちばん最後**に、カンマを足してこの1行を書き足す

   ```
   "https://www.googleapis.com/auth/calendar.readonly"
   ```

   直前の行の末尾に **, （カンマ）** を付け忘れないこと。書き足したあとの形はこのフォルダの
   `tools/appsscript.json` と同じになります（※そちらは**貼り付け用の見本**です。
   いま入っている4本と違っていたら、**丸ごと貼り替えず、上の1行だけを足してください**）。

5. 💾 保存
6. `runNow` を1回実行 → **「承認が必要です」** が出るので、自分のアカウントで承認する
   （「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」）
7. もう一度 `runNow` を実行して、実行ログに `Googleカレンダー: 枠◯件…` が出れば成功

## 承認をまだしていないとどうなる？

`data.json` は壊れません。カレンダーだけが読めず、実行ログに
`⚠️ カレンダーを読めませんでした` が出て、アプリの会食カードが
「カレンダーがまだつながっていません」と表示します。他のカードは今までどおり動きます。
